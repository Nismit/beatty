Beatty - Help

Keyboard Shortcuts

Mac: Ctrl / Windows: Ctrl+Shift

  • P Play / Pause
  • I Reset (Initialize)
  • C Compile Shader
  • A Apply Compiled Shader
  • V Editor Visibility
  • M Mode Switch (Sound/Visual)
  • D Debug Overlay
  • ? Show Help

Control Buttons

Tap buttons on the right sidebar:

  • ▶ Play / Pause
  • ↺ Reset
  • ⚙ Compile Shader
  • ✓ Apply Compiled Shader
  • 📝 Show / Hide Editor
  • 🎵 Sound Mode
  • 🎨 Visual Mode

Status Bar

The status bar background color indicates the current editor mode:

  • Sound Mode
  • Visual Mode

The dot indicator shows the shader state:

  • Ready
  • Compiling
  • Compiled
  • Applied
  • Error

Sound Shader Uniforms

  • float u_bpm - Beats per minute
  • float u_sampleRate - Audio sample rate
  • float u_blockOffset - Current audio block offset

Visual Shader Uniforms

  • vec2 u_resolution - Screen resolution
  • float u_time - Current time in seconds
  • float u_kick - Low frequency band (20-80 Hz) - kick drum range
  • float u_hihat - High frequency band (5000-12000 Hz) - hi-hat range
  • float u_bass - Mid-low frequency band (100-300 Hz) - bass range
