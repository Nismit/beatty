Beatty - Help

Keyboard Shortcuts

  • ⌘P Play/Pause
  • ⌘I Reset
  • ⌘S Compile Shader
  • ⌘R Apply Compiled Shader
  • ⌘T Toggle Editor Visibility
  • ⌘E Switch Sound/Visual Mode

Sound Shader Uniforms

  • float u_bpm - Beats per minute
  • float u_sampleRate - Audio sample rate
  • float u_blockOffset - Current audio block offset

Visual Shader Uniforms

  • vec2 u_resolution - Screen resolution
  • float u_time - Current time in seconds
  • float u_kick - Low frequency band (20-80 Hz) - kick drum range
  • float u_hihat - High frequency band (5000-12000 Hz) - hi-hat range
  • float u_bass - Mid-low frequency band (100-300 Hz) - bass range
